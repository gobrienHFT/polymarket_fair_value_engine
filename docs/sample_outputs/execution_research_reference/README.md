# Execution Research Reference

Generated by `python scripts/refresh_execution_research.py` from:

- input: `data/sample_execution_replay.jsonl`
- config: `configs/execution_research.json`
- engine version: `execution-research-v1`

This committed pack is a deterministic execution-research fixture. It compares passive and aggressive execution under conservative, base, and aggressive visible-depth assumptions, with lifecycle events, risk decisions, fills, markouts, accounting, model-edge attribution, markout coverage slices, and one-factor sensitivity rows. It consumes replayed `fair_yes` values; it does not claim to calibrate them, and it does not claim live football execution, participant-level FIFO, historical fill truth, or production alpha.

Start with `execution_report.md`, then trace `execution_casebook.md`, `execution_attribution.csv`, `execution_markout_slices.csv`, `execution_replay_validity.csv`, and `execution_lifecycle_events.csv`. `summary.json` includes input, config, code, and per-artifact SHA-256 hashes.
