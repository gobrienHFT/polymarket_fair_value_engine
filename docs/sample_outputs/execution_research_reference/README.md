# Binary Execution Research Reference

Generated by `python scripts/refresh_execution_research.py` from:

- input: `data/sample_execution_replay.jsonl`
- config: `configs/execution_research.json`
- engine version: `execution-research-v1`

This is the reproducible execution-research run for the bundled binary CLOB replay. It compares passive and aggressive execution under conservative, base, and aggressive visible-depth assumptions, then records lifecycle events, risk decisions, fills, markouts, accounting, model-edge attribution, markout coverage slices, and one-factor sensitivity rows. It starts with replayed `fair_yes` values rather than calibrating them. It also does not model live football execution, participant-level FIFO, historical fill truth, or production alpha.

Start with `execution_report.md`, then trace `execution_casebook.md`, `execution_attribution.csv`, `execution_markout_slices.csv`, `execution_replay_validity.csv`, and `execution_lifecycle_events.csv`. `summary.json` records the input, config, code, and SHA-256 hash for each output file.
